Automatic Bottle Filling and Capping System

Description

This project simulates an automatic bottle filling, capping and packing sequence using PLC ladder logic with timers, conveyor control, sensors and counter operation.

Inputs

- Start
- Stop
- Bottle Present Sensor
- Bottle Not Filled Sensor

Outputs

- Conveyor
- Filling Valve
- Capping Unit
- Packing Output

Features

- Start/Stop latch control
- Conveyor-based bottle movement
- Sensor-based filling and capping sequence
- Timer-controlled operations
- Bottle counting using counter
- Automatic packing after preset count

Timers

- T1 = Filling Time
- T2 = Capping Time

Counter

- CTU = Bottle Counter
- PV = 5 (Preset Count)

Tool Used

- Online PLC Simulator
