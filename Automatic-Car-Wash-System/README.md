Automatic Car Washing System

Description

This project simulates an automatic car wash sequence using PLC ladder logic with timers, conveyor control, and sensor-based stage operation.

Inputs

- Start
- Stop
- Entry Sensor
- Exit Sensor
- S1
- S2
- S3
- S4

Outputs

- Conveyor
- Soap Water
- Brushes
- Clear Water
- Dryer
- Cycle

Features

- Start/Stop latch control
- Conveyor-based car movement
- Sensor-based sequential washing stages
- Timer-controlled operations
- Automatic cycle completion

Timers

- T1 = Soap Wash
- T2 = Brushing
- T3 = Clear Water Rinse
- T4 = Drying
- T5 = Cycle Completion

Tool Used

- Online PLC Simulator
